Меню, рівні та ефекти

Unity PRO · Tower Defense · самостійна робота після уроків 6–8

Що ми зробимо. Продовження після уроків 6–8: меню з кількома рівнями і ефекти (сніг, «+50» над ворогом, трясіння камери). Інтерфейс (панелі, іконки, картки магазину) — у гайді уроку 5 «Від примітивів до готової гри».

Частина 1 · Меню і рівні

1Зроби другий рівень

  1. У вікні Project виділи сцену гри і натисни Ctrl+D. Перейменуй копії: Level1 і Level2.
  2. Відкрий Level2 і зміни її: переклади дорогу інакше, у BuildManager зміни Start Coins, у замку (Castle) — кількість Hp.
  3. Дорога змінилась — вороги мають знати новий шлях. Виділи об'єкт з NavMeshSurface і натисни Bake.
Вороги йдуть крізь траву? Ти забув перепекти NavMesh після зміни дороги (крок 3).

2Сцена меню

  1. File → New Scene, збережи як Menu.
  2. GameObject → UI → Canvas. У Canvas Scaler: UI Scale Mode = Scale With Screen Size, Reference Resolution = 1920 × 1080.
  3. Додай дві кнопки: GameObject → UI → Button - TextMeshPro. Напиши на них «Level 1» і «Level 2».
  4. Створи скрипт LevelMenu і додай його на Canvas:
using UnityEngine;
using UnityEngine.SceneManagement;

public class LevelMenu : MonoBehaviour
{
    // Відкриває сцену за назвою — назву пишемо в кнопці
    public void Load(string sceneName)
    {
        Time.timeScale = 1f;
        SceneManager.LoadScene(sceneName);
    }

    public void LoadMenu()
    {
        Load("Menu");
    }
}
  1. Виділи кнопку. У On Click () натисни +, перетягни туди Canvas, вибери LevelMenu → Load і впиши назву сцени, наприклад Level2.

3Додай сцени у збірку і кнопку «Меню»

  1. File → Build Profiles → Scene List: перетягни туди Menu (першою!), потім Level1, Level2.
  2. У кожному рівні додай на Canvas скрипт LevelMenu і кнопку «Menu», яка викликає LevelMenu → LoadMenu.
Помилка «Scene couldn't be loaded»? Сцени немає в Scene List або назва в кнопці написана з помилкою (великі й малі літери важливі).

Частина 2 · Ефекти

4Сніг — без жодного рядка коду

Відео з усіма кроками: snow-slides.mp4 (1 хвилина).

  1. Hierarchy → ПКМ → Effects → Particle System, назви Snow.
  2. Transform: Position Y = 6, Rotation X = 90 — частинки летітимуть униз.
  3. Головний модуль: Start Lifetime 7, Start Speed 1, Start Size 0.2, Start Color світло-блакитний, Max Particles 600, ✓ Prewarm (сніг уже йде на старті).
  4. Emission: Rate over Time = 100.
  5. Shape: Shape = Box, Scale = 14 × 14 × 0.1 — сніг падає з усієї площі поля.
  6. Увімкни Noise, Strength = 0.3 — сніжинки гойдаються.
Інша погода з тієї ж системи: пісок — колір жовтуватий, Rotation X = 0 і швидкість убік; світлячки — жовто-зелені, маленькі, Speed 0 і сильний Noise.

5«+50» над переможеним ворогом

  1. GameObject → 3D Object → Text - TextMeshPro. Назви RewardText, Font Size 6, вирівнювання по центру, колір жовтий.
  2. Додай на нього скрипт FloatUp — текст піднімається і зникає:
using UnityEngine;

public class FloatUp : MonoBehaviour
{
    [SerializeField] private float speed = 1.5f;
    [SerializeField] private float lifetime = 1f;

    void Start()
    {
        Destroy(gameObject, lifetime); // знищиться сам через секунду
    }

    void Update()
    {
        transform.position += Vector3.up * speed * Time.deltaTime;
        transform.rotation = Camera.main.transform.rotation; // завжди дивиться в камеру
    }
}
  1. Перетягни RewardText у Assets/Prefabs і видали зі сцени.
  2. У EnemyHealth зроби так само, як з boomFX (виділені рядки — нові):
using TMPro;   // угорі файлу
...
[SerializeField] private GameObject boomFX;
[SerializeField] private GameObject rewardText;
...
Instantiate(boomFX, transform.position, Quaternion.identity);
GameObject text = Instantiate(rewardText, transform.position + Vector3.up, Quaternion.identity);
text.GetComponent<TMP_Text>().text = "+" + reward;
Destroy(gameObject);
  1. У префабах ворогів перетягни RewardText у нове поле Reward Text.

6Трясіння камери, коли ворог дійшов до замку

Додай скрипт CameraShake на Main Camera. Він зроблений як singleton — так само, як BuildManager з уроку 3.

using UnityEngine;

public class CameraShake : MonoBehaviour
{
    public static CameraShake Instance;

    [SerializeField] private float duration = 0.3f;
    [SerializeField] private float strength = 0.2f;

    private Vector3 startPosition;
    private float timer;

    void Awake()
    {
        Instance = this;
    }

    void Start()
    {
        startPosition = transform.position;
    }

    public void Shake()
    {
        timer = duration;
    }

    void Update()
    {
        if (timer > 0)
        {
            timer -= Time.deltaTime;
            transform.position = startPosition + Random.insideUnitSphere * strength;
        }
        else
        {
            transform.position = startPosition;
        }
    }
}

У Castle після рядка hp--; додай:

CameraShake.Instance.Shake();

★Для тих, хто встиг

  • Червоний спалах: UI Image на весь екран, червоний з прозорістю 0. У CameraShake.Shake() зроби її напівпрозорою, а в Update плавно повертай прозорість до 0.
  • Турель «вискакує»: у Start турелі постав transform.localScale = Vector3.zero, а в Update плавно збільшуй до 1.
  • Пил при будівництві: Particle System з одним Burst у модулі Emission, створюй його в Node.Build так само, як boomFX.
