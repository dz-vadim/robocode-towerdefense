Від примітивів до готової гри

Unity PRO · урок 5 «Самостійна робота. Покращення гри» · основа — твій проєкт після уроку 4

Відео всіх кроків (2,5 хв): lesson5-makeover.mp4 — від сцени з кубиків до готової гри.
Що ми зробимо. Логіка гри лишається твоєю — скрипти з уроків 1–4 не змінюються. Ми переодягнемо гру: частина 1 — готові 3D-моделі замість примітивів, частина 2 — інтерфейс, який не соромно показати на телефоні. Розрахунок — 2 заняття (по одній частині).

Частина 1 · Моделі

Детальніша версія з поясненнями кожного тайла — у гайді «Нова графіка для Tower Defense». Тут — короткий шлях.

1Завантаж і імпортуй набір Kenney

  1. kenney.nl/assets/tower-defense-kit → Download, розпакуй.
  2. Створи Assets/Kenney/TowerDefenseKit/Models і перетягни туди все з Models/FBX format разом із текою Textures.
  3. Створи один матеріал Kenney: Shader Universal Render Pipeline/Lit, у Base Map — colormap.png, Smoothness ≈ 0.15. Усі моделі набору фарбуються ним.
Ліцензія CC0: моделі можна використовувати в будь-якій грі, навіть платній.

2Вузли стають трав'яними тайлами

  1. Відкрий префаб Node: Scale = 1, 1, 1; Mesh = tile; Material = Kenney.
  2. Box Collider: Center 0, 0.3, 0 · Size 1, 0.6, 1. BuildPoint: Position Y = 0.2.
  3. Тайли мають розмір рівно 1×1 — розстав вузли впритул із прив'язкою до сітки з кроком 1, а на місці дороги лиши порожні клітинки.

3Дорога з тайлів і NavMesh

  1. Створи порожній Road і склади в ньому дорогу з tile-straight, tile-corner-round, tile-spawn-end-round (старт) і tile-end-round (фініш). Повертай тайли по Y на 90°, щоб з'єднати ділянки.
  2. Plane: вимкни лише компонент Mesh Renderer (сам Plane не видаляй — по ньому ходять вороги), Position Y = 0.1.
  3. Plane → NavMesh Surface → Bake. Синя сітка має бути тільки на дорозі.

4Турелі та вороги

  • Турель: у префабі заміни модель основи на tower-round-bottom-a (Scale 0.8, 0.6, 0.8), а гармату всередині Weapon — на weapon-cannon (для інших турелей weapon-turret, weapon-ballista). Weapon підніми на Y ≈ 0.36. Скрипт, Sphere Collider і шар Ignore Raycast не чіпай.
  • Ворог: у префабі Enemy видали Mesh Filter і Mesh Renderer, вклади модель enemy-ufo-a (Scale ≈ 0.55). NavMesh Agent: Radius 0.25, Base Offset 0.15.

5Спавн, замок, ліс і камера

  1. На старт дороги — spawn-round. На фініш — замок із частин башти: tower-square-bottom-b → middle-a → top-a → roof-b. Кубу FinishPoint вимкни лише Mesh Renderer.
  2. Навколо поля — tile-tree, tile-tree-double, tile-tree-quad, tile-rock, повернуті по-різному.
  3. Main Camera: Position 0, 8.6, -7.4 · Rotation X 52 · Background — зелений під колір трави.
  4. Іконки магазину: з теки Previews архіву імпортуй weapon-cannon.png та інші як Sprite і вкажи їх у полі Icon своїх TurretInfo.
Моделі білі — у матеріалі немає colormap.png. Рожеві — шейдер не URP. Вороги йдуть по траві — перепечи NavMesh (крок 3).

Частина 2 · Інтерфейс

6Іконки і заокруглена картинка

Завантаж (правою кнопкою → «Зберегти як») і перетягни в Assets/Sprites/UI:

coin heart star play home rounded
  1. Виділи всі картинки → Texture Type = Sprite (2D and UI) → Apply.
  2. Для rounded: Sprite Editor → Border = 52 з усіх боків → Apply. Тепер з неї можна зробити панель будь-якого розміру, а кути не розтягнуться.
heart, play і home знадобляться пізніше — для здоров'я замку, кнопки хвилі та меню на уроках 6–8.

7Canvas під телефон і якорі

  1. Canvas → Canvas Scaler: UI Scale Mode = Scale With Screen Size, Reference Resolution = 1920 × 1080, Match = 0.5.
  2. Кожен елемент прив'яжи до свого краю: Rect Transform → Anchor Presets, затисни Alt і клікни кут. Монети — лівий верхній, магазин — ліворуч по центру.
  3. Перевір: у вікні Game перемкни розмір на 2400×1080 (як телефон) — нічого не має вилізти за край.

8Панель монет

  1. На Canvas: UI → Image, назви CoinsPanel. Source Image = rounded, Image Type = Sliced, колір — темно-синій напівпрозорий. Розмір 280 × 100, якір — лівий верхній кут, Pos 140, -24.
  2. Усередину — ще одна Image з coin, 72 × 72, ліворуч.
  3. Перетягни свій текст монет у панель і постав праворуч від іконки: шрифт Bold, розмір 56, вирівнювання ліворуч.
  4. У тексті: Material Preset → LiberationSans SDF - Outline — з'явиться обведення, і число читатиметься на будь-якому фоні.

9Картки магазину

Кнопки магазину створює ShopPanel з префаба — тому змінюємо префаб, і всі кнопки оновляться разом.

  1. ShopPanel: Image = rounded (Sliced), темний напівпрозорий; у Vertical Layout Group — Padding 16, Spacing 16.
  2. Відкрий префаб SelectTurretButton. Його Image: rounded, Sliced, колір #2E3854.
  3. У Button: Transition = Color Tint, Pressed Color — сірий. Кнопка темнішатиме при натисканні.
  4. Біля ціни додай Image з coin 36 × 36, а CostLabel зсунь праворуч і теж постав йому preset Outline.
Кнопки налізли одна на одну? У Vertical Layout Group вимкни Child Force Expand → Height і задай панелі висоту під кількість карток.

10Перевір і збери

  • Тисни Play: монети в панелі, картки натискаються, турелі будуються.
  • Клік по картці не має будувати турель під нею — це ми виправляли на уроці 4.
  • Перемкни Game на 2400×1080 і на 1280×720 — усе на місці.

★Для тих, хто встиг

  • Підсвітка вибраної турелі: у ShopPanel збережи фони кнопок у List<Image>; у слухачі кліку спочатку всім постав звичайний колір, а натиснутій — золотий.
  • Назва турелі на картці: додай у TurretInfo поле title і текст на картці, який заповнює SelectTurretButton.SetTurretInfo.
  • Інші світи: набори Forest / Desert / Dungeon з Asset Store — див. додаткове завдання в гайді Kenney.
