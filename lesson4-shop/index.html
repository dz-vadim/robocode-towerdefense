1Спершу виправимо баг з уроку 3

У BuildManager підписка йде лямбдою, а лямбду не можна відписати: -= отримує новий об'єкт. Передаємо сам метод:

private void OnEnable()
{
    _buildAction.Enable();
    _buildAction.started += InteractWithNode;
}

private void OnDisable()
{
    _buildAction.Disable();
    _buildAction.started -= InteractWithNode;
}

2TurretInfo — «картка» турелі

Новий скрипт TurretInfo. Це ScriptableObject: не компонент на об'єкті, а файл-дані в проєкті.

using UnityEngine;

[CreateAssetMenu(fileName = "TurretInfo", menuName = "Scriptable Objects/TurretInfo")]
public class TurretInfo : ScriptableObject
{
    public Sprite icon;
    public int cost = 0;
    public GameObject turretPrefab;
}
  1. Три картинки в Sprite: Texture Type = Sprite (2D and UI) → Apply.
  2. У теці ScriptableObjects: Create → Scriptable Objects → TurretInfo — тричі. Заповни: StandardTurret 100, BigTurret 200, SlowTurret 150, іконку і префаб кожної турелі.

3Кнопка магазину

using TMPro;
using UnityEngine;
using UnityEngine.UI;

public class SelectTurretButton : MonoBehaviour
{
    [SerializeField] private Image image;
    [SerializeField] private TMP_Text costLabel;

    public void SetTurretInfo(TurretInfo info)
    {
        image.sprite = info.icon;
        costLabel.text = info.cost.ToString();
    }
}
  1. На Canvas: UI → Button - TextMeshPro, назви SelectTurretButton, розмір 150 × 170. Текст усередині видали.
  2. Додай дочірні Image (іконка, вгорі) і Text - TextMeshPro CostLabel (ціна, внизу).
  3. Додай скрипт SelectTurretButton, перетягни в поля Image і CostLabel.
  4. Перетягни кнопку в Prefabs і видали зі сцени — кнопки створюватиме скрипт.

4Панель магазину

using System.Collections.Generic;
using UnityEngine;
using UnityEngine.UI;

public class ShopPanel : MonoBehaviour
{
    [SerializeField] private GameObject buttonPrefab;
    [SerializeField] private List<TurretInfo> turretInfos;

    private void Start()
    {
        foreach (TurretInfo turretInfo in turretInfos)
        {
            GameObject button = Instantiate(buttonPrefab, transform);
            button.GetComponent<SelectTurretButton>().SetTurretInfo(turretInfo);
            button.GetComponent<Button>().onClick.AddListener(
                () => BuildManager.Instance.ChangeCurrentTurret(turretInfo));
        }
    }
}

У BuildManager — метод вибору турелі і перевірка, щоб клік по магазину не будував турель під кнопкою:

using System.Collections.Generic;
using UnityEngine.EventSystems;
using UnityEngine.UI;
...
public void ChangeCurrentTurret(TurretInfo info)
{
    _currentCost = info.cost;
    _currentTurret = info.turretPrefab;
}

public void InteractWithNode(InputAction.CallbackContext callbackContext)
{
    Vector2 mousePosition = callbackContext.ReadValue<Vector2>();
    if (IsPointerOverUI(mousePosition)) return;
    ...
}

private bool IsPointerOverUI(Vector2 position)
{
    var data = new PointerEventData(EventSystem.current) { position = position };
    var results = new List<RaycastResult>();
    EventSystem.current.RaycastAll(data, results);
    foreach (var r in results)
        if (r.module is GraphicRaycaster) return true;
    return false;
}
  1. На Canvas: UI → Panel, назви ShopPanel, прив'яжи ліворуч по центру (180 × 560).
  2. Додай Vertical Layout Group (Spacing 12, Child Alignment — Middle Center, зніми галочки Control Child Size).
  3. Додай скрипт ShopPanel: префаб кнопки і три TurretInfo у список.
Турель будується під кнопкою магазину? Немає перевірки IsPointerOverUI з кроку 4.

5Вибух BoomFX

Hierarchy → ПКМ → Effects → Particle System, назви BoomFX:

МодульЩо поставити
ГоловнийDuration 0.5 · Looping ✗ · Start Lifetime 1 · Start Speed 2–4 · Start Size 0.05–0.15 · Gravity Modifier 1 · Stop Action = Destroy
EmissionRate over Time 0 · Bursts: +, Count 60
ShapeHemisphere, Radius 0.2
Collision✓, Type World, Bounce 0.3
RendererRender Mode = Mesh, Mesh = Cube, Material = матеріал ворога

Перетягни в Prefabs, зі сцени видали.

7Звуки

Завантаж звуки (правою кнопкою → «Зберегти як») у Assets/Audio: Shoot1 · Shoot2 · Build · Explosion.

  1. Create → Audio → Audio Random Container, назви Shoot. Додай Shoot1 і Shoot2, Playback Mode — Random, увімкни розкид Pitch — постріли не будуть однаковими.
  2. У кожному префабі турелі на Weapon (де скрипт Turret) додай Audio Source: Audio Resource = Shoot, зніми Play On Awake.
  3. На BuildManager — ще один Audio Source з Build.wav, без Play On Awake.
// Turret.cs
private AudioSource _audioSource;

private void Start()
{
    _audioSource = GetComponent<AudioSource>();
    StartCoroutine(Fire());
}
...
    _enemies[0].TakeDamage(_damage);
    _audioSource.Play();

// BuildManager.cs
[SerializeField] private AudioSource _buildSound;
...
    node.Build(_currentTurret);
    _buildSound.Play();

8Перевір

  • Магазин показує 3 турелі з цінами, клік по картці змінює турель.
  • Турель не будується, коли клікаєш по магазину.
  • Ворог розлітається на кубики, монети додаються.
  • Чути постріли (різні) і звук будівництва.
